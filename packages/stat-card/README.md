# @srisaa/stat-card

KPI tile: label above a large value.

Selector: `sd-stat-card`

```html
<sd-stat-card label="Total" [value]="30" valueClass="text-blue-700" />
```

API: label, value, valueClass

Peer deps: Angular 19+. Uses Tailwind utility classes: add this package's `dist` to your Tailwind `content`.

Build: `npm run build` (ng-packagr) -> `dist/`.
